# HR Employee Attrition Analysis

## Project Overview

This project analyzes employee attrition using Excel and Power BI.

## Tools Used

- Microsoft Excel
- Power BI
- DAX

## Key KPIs

- Total Employees: 1,470
- Employees Left: 237
- Attrition Rate: 16.12%
- Average Monthly Income: 6,502.93
- Average Tenure: 7.01 years

## Analysis

The dashboard analyzes employee attrition based on:

- Department
- Job Role
- Age Group
- Gender
- Overtime
- Monthly Income

## Dashboard

The Power BI dashboard provides an interactive overview of employee attrition and helps identify patterns in employee turnover.
